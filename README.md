# Clinical Trial Matching & Simulated Attrition Risk

A Python notebook that takes 100,000 synthetic patient records, works out which patients would qualify for two real type 2 diabetes trials, and trains models to estimate each patient's risk of dropping out.

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/rayankhan06/clinical-trial-matching/blob/main/Clinical_Trial_Matching_Attrition.ipynb)

> **Read this first:** all patients are synthetic (generated by [Synthea](https://synthea.mitre.org/)), and the dropout outcome is **simulated** using a rule I wrote. This project demonstrates a data science workflow. It does not produce real medical findings.

## What it does

1. **Builds a patient-level table.** Four relational tables (patients, conditions, medications, lab observations) are joined into one row per patient, with age, diagnosis flags, latest HbA1c and eGFR, and medication counts. The multi-million-row observations file is read in chunks.
2. **Matches patients to trials.** Eligibility criteria from two ClinicalTrials.gov trials are translated by hand into True/False checks. The output is an eligibility funnel per trial and a pass/fail audit trail for every patient.
3. **Simulates dropout and models it.** I define a documented dropout rule (distance to a fake trial site, medication count, neuropathy, plus randomness), then train logistic regression and XGBoost. Permutation importance checks whether the models recover the rule I planted and ignore a pure-noise column.

## Trials used

| Trial | Sponsor | Description |
|---|---|---|
| [NCT06045221](https://clinicaltrials.gov/study/NCT06045221) | Eli Lilly | Orforglipron vs oral semaglutide in type 2 diabetes not controlled on metformin |
| [NCT06660173](https://clinicaltrials.gov/study/NCT06660173) | Amgen | Maridebart cafraglutide in type 2 diabetes (phase 2, dose-ranging) |

Neither trial is recruiting any more. They are used as real examples of eligibility criteria, not for live recruitment.

## Results

**Eligibility funnels** (100,000 synthetic patients; 5,693 adults with type 2 diabetes):

- **NCT06045221 (Lilly):** 100,000 → 79,312 adults → 5,693 with T2D → 729 with HbA1c 7.0-10.5% → 155 on metformin → 131 without retinopathy → **79 eligible** (eGFR of at least 45)
- **NCT06660173 (Amgen):** 100,000 → 79,312 adults → 5,693 with T2D → 729 with HbA1c 7.0-10.5% → 717 not on insulin → 526 with eGFR of at least 30 → **363 eligible** (no retinopathy)

**Dropout models** (simulated outcome, evaluated on a held-out 20% of patients):

- The simulated dropout rate is about 38%.
- Logistic regression and XGBoost both reach an AUC of about 0.70. They score about the same because the rule I simulated is mostly linear, so the tree model has nothing extra to find.
- The notebook also computes the best possible AUC given the randomness built into the outcome, as a ceiling for comparison.
- Permutation importance shows both models recovered the planted drivers: distance to the trial site and medication count are the strongest, neuropathy comes next, and the pure-noise column sits near zero.

## Design decisions

- **"Active" means no stop date.** A diagnosis or prescription with no `STOP` date counts as current.
- **Latest lab value only.** Each patient's most recent HbA1c and eGFR are used.
- **Missing labs never match a trial.** If a value is missing, eligibility can't be confirmed. For modeling, missing values are filled with the median inside a pipeline fitted on training data only, to avoid leakage.
- **Rules are plain True/False columns,** so every eligibility decision can be traced back to the specific check that passed or failed.
- **Risk scores are cross-validated,** so each patient's score comes from a model that never saw them.

## Limitations

- **The patients are synthetic.** Synthea is realistic enough to practice on, but it is not real evidence.
- **The dropout outcome is simulated.** Synthea has no trial or dropout data. The weights in the dropout rule are illustrative assumptions I chose, not clinical estimates. The model finding the rule shows the pipeline works, not that these factors drive real dropout.
- **Only some criteria are modeled.** The unmodeled ones are listed in the notebook (Section 6). Some, like BMI and time-based rules, could be added because Synthea records them.
- **The retinopathy checks are stricter than the trials' rules,** which only exclude treated or unstable cases. The data doesn't show severity or treatment.
- **Amgen's medication rule is simplified** to "not on insulin", since only metformin and insulin are flagged.
- **Labs use only the latest value,** while real criteria often require a time window (for example, "within 3 months").
- **Trial sites and distances are made up.** Distance is an approximate straight line, not travel time.
